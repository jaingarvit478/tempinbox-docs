# Security

**Effective date:** February 1, 2026

We take reasonable measures to protect the TempInbox service and its users.

## Security practices

- Encryption in transit for web and API traffic.
- Access controls and least‑privilege for infrastructure.
- Rate limiting and abuse detection.
- Regular maintenance and monitoring.

## Responsible disclosure

If you discover a security issue, please report it via the support web form. Include steps to reproduce and any relevant logs or timestamps.

## Limitations

No system can guarantee absolute security. Please avoid using TempInbox for sensitive or high‑risk data.
