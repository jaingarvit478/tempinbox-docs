## What is TempInbox?

TempInbox ([tempinbox.dev](https://tempinbox.dev)) is a free disposable inbox service. Select **Create inbox**, complete any required security check, and copy the generated address to receive email. No account or inbox password is required. There is no minute countdown, but temporary retention applies.

You can keep up to **3 persistent inboxes** per browser session. Access data stays in that browser profile; message availability is subject to temporary storage policy. There is no fixed lifetime or permanent retention guarantee.

## Key facts

| Property | Value |
| --- | --- |
| Inboxes per session | Up to 3 |
| Signup required | No |
| Expiry timer | No minute countdown; temporary retention applies |
| Outbound sending | Not supported (receive-only) |
| API | No supported public automation API |
| Address format | `anything@tempinbox.dev` |
| Languages | English, German |
| Cost | Free |

## What it's for

- Receiving OTP codes, magic links, and verification emails
- Signing up for trials and gated content without using your real address
- Developer and QA testing of email-dependent signup flows
- Manual QA of email verification steps; unattended CI needs separate supported infrastructure

## What it's NOT for

<Warning>
  Do not use temporary email for accounts where long-term access matters: banking, healthcare, legal accounts, primary social media, or any service requiring email-based account recovery.
</Warning>

TempInbox is also **receive-only** — it accepts inbound SMTP mail but does not support sending outbound email.
