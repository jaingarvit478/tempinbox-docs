TempInbox saves inbox access in your browser, but does not promise a fixed inbox lifetime or permanent message storage. Keeping an inbox listed is different from keeping every email stored.

## What survives closing a tab?

Closing a normal tab does not itself clear saved browser data. Returning in the same profile can preserve access if the local data remains and the inbox is still available on the service.

| Action | What to expect |
| --- | --- |
| Close a tab or restart the browser | Normally preserves local access data; does not guarantee message retention |
| Clear site data | Can remove the data needed for inbox access |
| Use another browser, profile, or device | Does not automatically transfer access |
| End private browsing | Normally clears that private session's temporary browser storage |

## Can I extend retention?

No retention extension is promised for refreshing, receiving another message, or keeping a tab open. There is no published guaranteed storage duration. Messages can be soft-deleted before permanent removal in scheduled cleanup batches.

Copy anything you need later into storage you control. Use a durable mailbox for ongoing account recovery or long-term archives. Clearing local data does not itself guarantee immediate server-side erasure.
