## Browser (no code)

<Steps>
  <Step title="Open TempInbox">
    Go to [tempinbox.dev](https://tempinbox.dev). No signup is required.
  </Step>
  <Step title="Create an inbox">
    Select **Create inbox** and complete any required security check. Wait until your generated address is displayed.
  </Step>
  <Step title="Copy the address">
    Click the copy icon next to the address (e.g. `swift-cloud-7x4@tempinbox.dev`).
  </Step>
  <Step title="Use it in an accepted signup form">
    Paste it into a signup or verification form that accepts temporary addresses. The inbox updates automatically when mail arrives.
  </Step>
  <Step title="Read your email">
    Click the email in the inbox to open it. Copy verification codes or click magic links directly.
  </Step>
</Steps>

Address creation and email delivery are separate steps. The sending service must accept the address and deliver its message; TempInbox does not guarantee a delivery time. Use verification codes and links before the sender's expiry window ends.

TempInbox is receive-only: sending, replies, and forwarding are not supported. Up to three inboxes can be saved in the same browser profile. Saved access does not guarantee a fixed inbox lifetime or permanent message storage; clearing site data can remove your access.

## Self-hosted implementation examples

The hosted service has no supported public automation API. The examples below are for a deployment you operate; configure inbound routing and authentication and check its deployed version before use. Replace the illustrative host with your own deployment URL.

<CodeGroup>

```bash cURL
# 1. Create a new address
curl -X POST https://your-worker.example.com/api/new_address \
  -H "Content-Type: application/json" \
  -d '{}' \
  -c cookies.txt   # save cookies required by your deployment

# Response:
# { "address": "swift-cloud-7x4@tempinbox.dev", "jwt": "eyJ..." }
```

```javascript Node.js
const res = await fetch('https://your-worker.example.com/api/new_address', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({}),
  credentials: 'include',
});
const { address, jwt } = await res.json();
console.log('Address:', address);

// 2. Poll for mail
const mails = await fetch('https://your-worker.example.com/api/mails?limit=10&offset=0', {
  headers: { Authorization: `Bearer ${jwt}` },
});
const { results } = await mails.json();
console.log('Emails:', results);
```

```python Python
import requests

session = requests.Session()

# 1. Create address
r = session.post('https://your-worker.example.com/api/new_address', json={})
data = r.json()
address = data['address']
jwt = data['jwt']
print(f'Address: {address}')

# 2. Poll for mail
r = session.get(
    'https://your-worker.example.com/api/mails',
    params={'limit': 10, 'offset': 0},
    headers={'Authorization': f'Bearer {jwt}'}
)
emails = r.json()['results']
print(f'Emails: {emails}')
```
